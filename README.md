# Lucid TV

A small static site featuring reflections on mind, meaning, and video.

## Current feature

**Non-Attachment in Buddhism** — a short commentary accompanying the video
[`-d7Xu4aNCwk`](https://youtu.be/-d7Xu4aNCwk), framing it through the
Buddhist teachings of *anicca* (impermanence), *dukkha* (suffering born of
clinging), and *anattā* (non-self).

## Run locally

Open `index.html` in any modern browser, or serve the directory:

```sh
python3 -m http.server 8000
# then visit http://localhost:8000
```

## Files

- `index.html` — the page, including the embedded video and commentary
- `styles.css` — typography and layout
